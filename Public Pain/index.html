How To Build Your First Website Using Github

HTML, CSS, JAVASCRIPT

HTML's main function works with angle brackets <>, allowing you to make diffrent headings, sizes, paragraphs, lists, containers (divs). CSS works as its assistant, adding "makeup" to the code. CSS writes to style it and make it look pretty using curly brackets {} to style fonts, background colors, font size, and much more.
