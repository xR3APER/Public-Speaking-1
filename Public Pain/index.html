Two tools. One website.

Give your page a structure,
then make it yours.

01 / HTML

Add the content

HTML (HyperText Markup Language) organizes your page into headings, paragraphs, links, images, and more.

02 / CSS

Style the page

CSS (Cascading Style Sheets) controls colors, fonts, spacing, layout, and how the page adapts to screens.

03 / YOUR SITE

Put them together

Link your stylesheet to your HTML file. Open the HTML file in a browser to see your website.

A tiny example

Two files.
That’s a website.

Create index.html and styles.css in the same folder. The HTML links to the CSS, and the browser displays the result.

✦ This example uses HTML and CSS only—there’s no JavaScript.

index.html
<h1>Hello, world!</h1>
<p>My first website.</p>
<link rel="stylesheet"
  href="styles.css">
styles.css
body {
  font-family: sans-serif;
  color: #245c45;
  padding: 2rem;
}
