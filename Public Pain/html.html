Creating Your Own Website

You use HTML code to write base commands for your upcoming websites you have to write code for the 6 diffrent sections of your website.

HTML is the bare code for which the webpage is built. HTML main functions work with <> (angle brackets), which allows you to make 6 different heading types, paragraphs, lists, containers and more.

Examples being:
< h1 >, creates a heading.
< p >, creates a paragraph.
< div >, creates a div(container).
